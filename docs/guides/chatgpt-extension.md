# PDF review in chat

On a host with Placekeeper's extension entrypoints, open a PDF's file menu and choose Placekeeper. This opens the reader directly without sending a chat message. Opening Placekeeper from the conversation returns to the current review or offers a PDF chooser and **Recent reviews**. Choose a recent review to resume its protected work, save destination, and last page, including after the service restarts. Canceling the chooser leaves existing review work intact. The installed application and plugin must contain the extension build; changing this checkout does not update an installed release.

The expanded reader supports PDF search, page navigation, annotation editing and save status. When the host exposes live reader tools, chat can inspect the accepted review, search with the reader's exact search behavior, reveal a search result or annotation, and navigate to a page. Search coverage distinguishes an incomplete search from zero matches. A changed PDF or query requires a fresh search. A collapsed reader expands before navigation completes. If live tools are unavailable, open the reader and use its search and navigation controls.

Select text or hover an annotation and choose the bot button, **Add selection to chat** or **Add annotation to chat**. Add an optional note, then choose **Add to chat** to attach the captured evidence and note as context. Your prompt text stays unchanged and no message is sent. Reopen the same annotation’s bot action to edit its note and update the attachment. Cancel retains the note locally for that reader session. If attaching fails, the note remains available to retry. The host does not currently expose an editor for notes inside its context pills.

The open review and current selection are automatically available as context in the current chat. There is no sharing-options menu. Background context does not confirm that a model has read the evidence. Removing an attached context group in the host keeps it removed on later reader updates; removing all app context pauses automatic publication for that invocation. Bot actions still let you explicitly attach particular evidence with a note.

When a connection is lost, editing pauses until Placekeeper verifies the current review. Accepted annotations and protected drafts remain retained. Close the panel normally; Placekeeper releases ownership when the host delivers its teardown or page-exit signal. If cleanup cannot arrive, the connection expires. Reopen the PDF from its file menu or **Recent reviews** to continue. The reopening dialog offers **Resume review** when it can safely restore the review, or **Open separate copy** to keep the earlier review independent. If the former connection is still active, **Check again** refreshes its status without taking ownership. No manual Close review action is required. Codex may not restore an open reader after quitting, so use Recent reviews to reopen it.

Cross-chat review snapshots are not currently available. If that feature is revisited, it should use an explicit action that clearly identifies the destination chat and captured revision; opening a PDF in one chat should not automatically make it discoverable elsewhere.

Click the PDF filename to choose where annotations are saved. **Save to a new copy** uses Placekeeper’s native folder picker: choose a folder and filename once, then accepted edits autosave to that copy. This works for read-only PDFs as well as writable PDFs and does not require downloading from Codex. Canceling the dialog keeps the current save destination. Resuming a protected review retains its chosen copy. If the host supplies a new file handle, Placekeeper may offer a saved-copy review with matching contents and a similar filename; choose **Resume review** only when it is the review you intend. A review still owned by another connection cannot be taken over; an independent review keeps its own work and save destination.

A writable host PDF can also save back through the host against its current version. If that source changes before saving, Placekeeper protects your work instead of overwriting it; choose a local copy to keep the annotated review. Follow the displayed save status and retry a failed save when needed. Downloading a separate reviewed copy is optional and depends on host support. When a host cannot provide a direct entrypoint or readable resource, use the displayed chooser or existing trusted local-PDF workflow. Supported host behavior is tracked separately in the [qualification record](../testing/chatgpt-extension-qualification.md).
