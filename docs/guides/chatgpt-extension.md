# PDF review in chat

On a host with Placekeeper's extension entrypoints, open a PDF's file menu and choose Placekeeper. This opens the reader directly without sending a chat message. Opening Placekeeper from the conversation returns to the current review or offers a PDF chooser and **Recent reviews**. Choose a recent review to resume its protected work, save destination, and last page, including after the service restarts. Canceling the chooser leaves existing review work intact. The installed application and plugin must contain the extension build; changing this checkout does not update an installed release.

The expanded reader supports PDF search, page navigation, annotation editing and save status. When the host exposes live reader tools, chat can inspect the accepted review, search with the reader's exact search behavior, reveal a search result or annotation, and navigate to a page. Search coverage distinguishes an incomplete search from zero matches. A changed PDF or query requires a fresh search. A collapsed reader expands before navigation completes. If live tools are unavailable, open the reader and use its search and navigation controls.

Select text and choose **Ask about this selection**, or open **Discuss annotations in chat**, choose the annotations, and select **Discuss these annotations**. These actions capture the chosen evidence and prepare an editable chat draft. Review it before sending; Placekeeper does not send it automatically. On hosts without editable draft support, copy the displayed draft and optionally choose **Attach captured evidence**.

**Sharing settings** contains global controls for background review context, current selection sharing, and explicitly included review snapshots for mentions in other chats. Settings load before automatic sharing starts. Background context reports that evidence is available to chat; it does not confirm that a model has read it. Removing a context group in the host keeps that group removed on later reader updates. Removing all app context pauses background sharing for that invocation; **Enable background context** resumes it when the global preference allows sharing. Explicit discussion attachments remain distinct from automatic background sharing.

Reviews are excluded from mentions by default. Enable the global snapshot preference, then choose **Include this review snapshot** for an individual review. On hosts that expose Placekeeper in the composer's mention menu, other chats can retrieve that captured snapshot, with its capture time and revision. The **Include review context** picker is available in the reader and the empty conversation chooser, even when the host has no mention menu. Search explicitly included snapshots, check their capture time, and choose **Include snapshot** to attach one without sending a message. Availability is checked again when selected; removed snapshots cannot be retrieved from an old search result. Later changes require **Update included snapshot**. Use **Remove this review from mentions** to remove it. This does not authorize access to every open review or make a snapshot live.

During a lost connection, editing pauses until Placekeeper verifies the current review. Accepted annotations and protected drafts remain retained. Use **Close review** inside Placekeeper to release the review before closing the panel. If the host closes the panel without cleanup, reopen Placekeeper and select the PDF from **Recent reviews** or its file menu. Once the former connection’s lease expires, **Recover disconnected review** explicitly transfers ownership while preserving accepted work and rejecting writes from the old panel. Recovery is rejected if that panel reconnects first; an actively connected review still requires an independent review. Codex may not restore an open reader after quitting, so use Recent reviews to reopen it. Choose whether to resume protected work or open an independent review when offered.

Click the PDF filename to choose where annotations are saved. **Save to a new copy** uses Placekeeper’s native folder picker: choose a folder and filename once, then accepted edits autosave to that copy. This works for read-only PDFs as well as writable PDFs and does not require downloading from Codex. Canceling the dialog keeps the current save destination. Resuming a protected review retains its chosen copy. If the host supplies a new file handle, Placekeeper may offer a saved-copy review with matching contents and a similar filename; choose **Resume protected review** only when it is the review you intend. A review still owned by another connection cannot be taken over; an independent review keeps its own work and save destination.

A writable host PDF can also save back through the host against its current version. If that source changes before saving, Placekeeper protects your work instead of overwriting it; choose a local copy to keep the annotated review. Follow the displayed save status and retry a failed save when needed. Downloading a separate reviewed copy is optional and depends on host support. When a host cannot provide a direct entrypoint or readable resource, use the displayed chooser or existing trusted local-PDF workflow. Supported host behavior is tracked separately in the [qualification record](../testing/chatgpt-extension-qualification.md).
