# PDF review in chat

On a host with Placekeeper's extension entrypoints, open a PDF's file menu and choose Placekeeper. This opens the reader directly without sending a chat message. Opening Placekeeper from the conversation returns to the current review or offers a PDF chooser. Canceling the chooser leaves existing review work intact. The installed application and plugin must contain the extension build; changing this checkout does not update an installed release.

The expanded reader supports PDF search, page navigation, annotation editing and save status. When the host exposes live reader tools, chat can inspect the accepted review, search with the reader's exact search behavior, reveal a search result or annotation, and navigate to a page. Search coverage distinguishes an incomplete search from zero matches. A changed PDF or query requires a fresh search. A collapsed reader expands before navigation completes. If live tools are unavailable, open the reader and use its search and navigation controls.

Select text and choose **Ask about this selection**, or open **Discuss annotations in chat**, choose the annotations, and select **Discuss these annotations**. These actions capture the chosen evidence and prepare an editable chat draft. Review it before sending; Placekeeper does not send it automatically. On hosts without editable draft support, copy the displayed draft and optionally choose **Attach captured evidence**.

**Sharing settings** contains global controls for background review context, current selection sharing, and explicitly included review snapshots for mentions in other chats. Settings load before automatic sharing starts. Background context reports that evidence is available to chat; it does not confirm that a model has read it. Removing a context group in the host keeps that group removed on later reader updates. Removing all app context pauses background sharing for that invocation; **Enable background context** resumes it when the global preference allows sharing. Explicit discussion attachments remain distinct from automatic background sharing.

Reviews are excluded from mentions by default. Enable the global snapshot preference, then choose **Include this review snapshot** for an individual review. Other chats receive that captured snapshot, with its capture time and revision. Later changes require **Update included snapshot**. Use **Remove this review from mentions** to remove it. This does not authorize access to every open review or make a snapshot live.

During a lost connection, editing pauses until Placekeeper verifies the current review. Accepted annotations and protected drafts remain retained. If the connection ends, reopen the PDF through its file menu. Use the explicit reopen action for recovery. Choose whether to resume protected work or open an independent review when offered.

A host PDF may be read-only or may require a conditional save against its current version. Follow the displayed save status. If the source changed before saving, export a reviewed copy before reopening the newer PDF. When a host cannot provide a direct entrypoint or editable resource, use the displayed chooser, export, or existing trusted local-PDF workflow. Supported host behavior is tracked separately in the [qualification record](../testing/chatgpt-extension-qualification.md).
